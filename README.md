# X 回复清理助手

一个 Chrome／Arc／Edge 扩展：用你自己的大模型 API，识别 X（推特）评论区里的 AI 自动回复和 AI 生成的推文；对看不顺眼的账号，一键隐藏或拉黑。

- **评论区 AI 回复识别**：每条回复旁显示「AI 分数」（0–100），悬停可以看到判断理由。
- **详情页主帖识别**：打开别人的推文时，主帖正文也能判断是不是 AI 写的。
- **个人主页 AI 推文识别**：分析一个账号自己发的推文，汇总显示「高嫌疑 N/M 条」，还能发现同一账号批量套用的模板。
- **黄推自动标记**：用本地规则识别色情引流回复，标红色「黄推」，不调用 API、不花钱。
- **一键隐藏、一键拉黑**：「隐藏」把发布者静音，对方不知道；「拉黑」先隐藏这条回复，再屏蔽发布者。

## 安装

目前需要手动加载，还没有上架 Chrome 应用商店。

1. 下载本仓库：点 GitHub 页面上的 **Code → Download ZIP** 并解压，或者 `git clone`。
2. 打开 `chrome://extensions`（Arc 用 `arc://extensions`，Edge 用 `edge://extensions`）。
3. 打开右上角的「开发者模式」。
4. 点「加载已解压的扩展程序」，选择解压后的文件夹（里面有 `manifest.json` 的那一层）。
5. 在扩展详情里打开「扩展程序选项」：选服务商，粘贴 API Key，点「测试连接」。

## 支持的服务商

AI 识别需要你自己的 API Key，费用由你的账号承担。插件作者不提供中转服务，也收不到你的 Key 和数据。

| 服务商 | 默认模型 | 获取 Key |
|---|---|---|
| DeepSeek | `deepseek-flash` | [platform.deepseek.com](https://platform.deepseek.com/api_keys) |
| OpenAI | `gpt-5.4-mini` | [platform.openai.com](https://platform.openai.com/api-keys) |
| Claude（Anthropic） | `claude-opus-5-5` | [console.anthropic.com](https://console.anthropic.com/settings/keys) |
| OpenRouter | `deepseek/deepseek-v4-flash` | [openrouter.ai](https://openrouter.ai/keys) |
| 自定义 | 自己填 | 任何 OpenAI 兼容接口，包括本机的 `localhost` 服务 |

- 模型名可以在「高级设置」里改。用 Claude 时，`claude-haiku-5-5` 比默认模型便宜得多。
- 选「自定义」时，点「测试连接」会请浏览器授权访问你填的那个地址。插件不会访问你没授权的网站。
- 每个服务商的 Key 分开保存，切换服务商不会覆盖。

## 使用

| 页面 | 方式 |
|---|---|
| 自己推文的详情页 | **自动检测**：新回复出现后约 2 秒合并成一批分析，右下角显示「自动检测 · 已分析 N 条」 |
| 别人推文的详情页 | **手动**：点右下角「扫描主帖和回复」，或点工具栏里的扩展图标。主帖正文和回复会分别打分，主帖使用推文版判断标准 |
| 某个人的主页 | **手动**：点「扫描本页推文」。只分析这个人自己发的推文，跳过转帖。往下滚动后再点一次，会分析新加载的推文 |
| 首页时间线、搜索、通知 | 不检测 |

分数颜色：灰色 0–30 像真人，黄色 31–69 可疑，红色 70–100 高度可疑。

### 黄推标记

黄推回复往往只有几个字，模型单看文字很难判断。插件用本地规则识别，所有详情页和主页都会自动运行，不调用 API：

- **黄推语录**：命中一条就标记，例如「只入身体不入生活」「急找主人」「线下可约」「t.me/」。比对时忽略空格、标点和 emoji。
- **弱词加账号特征**：「寂寞」「主人」「同城」等词正常人也会用，所以只有同时具备两项账号特征时才标记。账号特征包括：昵称带 🌸💕 等装饰 emoji、用户名是大小写随机混排的字母（例如 `ZOkRIOeM`）、正文是带 🥺💦 等 emoji 的短句。
- 被标记的回复显示红色「黄推」标签，悬停可以看到命中了哪条规则，也不会再发给模型分析。
- 在设置页可以关闭这项功能，也可以添加自定义语录（一行一条）。内置语录在设置页里可以查看。

- 分析结果在本机保存 7 天，再次打开同一条推文不会重复调用 API。
- 自动检测每天有上限（默认 300 条，可以在设置页修改）。用完后自动检测暂停，手动点击仍然可以分析。手动分析不计入上限。
- 自动检测遇到未配置 API 或请求出错时会暂停，右下角按钮会显示原因。

### 隐藏和拉黑

其他账号发的帖子下方会出现两个按钮：

| 按钮 | 做什么 |
|---|---|
| 隐藏 | 静音发布者（X 简体中文界面里叫「隐藏 @用户」），对方不知道；这条回复本身不动 |
| 拉黑 | 先隐藏这条回复，再屏蔽发布者。在别人的推文下面没有隐藏回复的权限，会直接屏蔽 |

支持推文详情页、`x.com/notifications` 和 `x.com/notifications/mentions`。

## 费用

以 DeepSeek `deepseek-flash` 实测：一次分析 5 条回复约 1000 输入 tokens（大部分命中缓存）和 350 输出 tokens。每次调用的固定开销约 750 tokens，每多一条回复增加约 100 tokens。按默认的每天自动 300 条上限，大约每天十几次调用。具体价格以各服务商官网为准。

## 隐私与数据

- **发出去的数据**：只把原帖和回复（或主页推文）的文字、作者用户名、回复距原帖的秒数，发给**你自己配置的**模型服务商。不读取私信、关注列表或其他账号数据。
- **插件作者收不到任何数据**：扩展没有服务器，不做统计，不上报。
- **API Key 的保存方式**：存在本机浏览器的扩展存储（`chrome.storage.local`）里，**没有加密**。能登录你电脑的人可以读到它。建议为这个扩展单独创建一个 Key，并在服务商后台设置用量上限。
- **分析结果**：只缓存在本机，7 天后过期。

## 风险与限制

- **分数是嫌疑分，不是精确概率**。推文回复很短，任何检测方法都会误判。拉黑前请自己看一眼。
- **自动化操作可能被 X 限制**。「隐藏」和「拉黑」是模拟点击菜单完成的，短时间内频繁操作可能触发 X 的限制。建议逐条处理，等看到成功提示再点下一条。
- **点击即执行，没有二次确认**。
- **依赖 X 的页面结构**。X 改版后，按钮可能失效或找不到菜单项，需要更新插件。
- **界面语言**：扩展界面目前只有中文。菜单匹配支持 X 的简体中文、繁体中文和英文界面，其他语言界面下「隐藏」「拉黑」按钮可能失效。

## 自定义判断标准

在设置页「高级设置」里可以修改两份判断标准：评论区回复、个人主页推文。

- 只需要写「怎么判断」。输出格式（JSON、0–100 分、理由）由插件自动追加，改不坏。
- 内容与默认标准相同时按默认处理，以后插件更新默认标准会自动跟随。
- 点「恢复默认」可以随时还原。

默认标准基于 [dbskill](https://github.com/dontbesilent2025/dbskill) 中 `dbs-ai-check` 的 AI 写作特征改造：只保留适用于短内容的特征，并补充了评论区特有的信号（万能回复、复述原帖、回复过快、批量雷同）。

## 开发

不需要构建，也不依赖任何第三方包。修改代码后，在扩展管理页点刷新图标，再刷新 X 页面即可。

| 文件 | 作用 |
|---|---|
| `manifest.json` | 扩展配置与权限 |
| `reply-cleaner.js` | 「隐藏」「拉黑」按钮 |
| `ai-detector.js` | 收集详情页回复或主页推文，显示扫描按钮、AI 分数标签和黄推标记 |
| `spam-rules.js` | 黄推本地识别规则与内置语录 |
| `prompt.js` | 回复版和推文版的判断标准，以及固定的输出格式 |
| `providers.js` | 支持的服务商与默认模型 |
| `llm.js` | 读取设置、调用模型、解析结果 |
| `store.js` | 分数缓存（7 天）与每日自动分析计数 |
| `background.js` | 后台：分析请求、测试连接、工具栏图标 |
| `options.html`／`options.js` | 设置页 |
| `icons/` | 扩展图标 |

### 测试

```bash
npm test
```

用模拟的浏览器接口测试后台逻辑（缓存、每日上限、各服务商的请求格式、自定义判断标准、错误提示等），以及黄推规则的命中与防误伤。

```bash
AI_PROVIDER=deepseek AI_API_KEY=你的Key npm run test:live
```

用真实 API 跑一组构造样例，检查提示词能否分开 AI 内容和真人内容，会产生少量费用。`AI_PROVIDER` 可以是 `deepseek`、`openai`、`anthropic`、`openrouter`、`custom`（另需 `AI_BASE_URL` 和 `AI_MODEL`）。Key 只从环境变量读取，请不要写进任何文件。

### 手动测试清单

页面行为依赖 X 的真实页面，改动 `ai-detector.js` 或 `reply-cleaner.js` 后，请在 X 上逐项确认：

1. 自己推文的详情页：右下角显示「自动检测」，约 2 秒后回复旁出现分数；往下滚动，新回复也会被分析；主帖不打分。
2. 编辑过的推文：同样能识别主帖。
3. 别人推文的详情页：只在点击按钮后才分析，主帖和回复都出现分数；往下翻到主帖看不见时点按钮也能分析；分析过的内容下次打开直接显示分数。
4. 个人主页：「帖子」和「回复」标签页都能扫描，转帖不计入。
5. 「隐藏」按钮：静音成功，没有弹出屏蔽确认框。
6. 「拉黑」按钮：在自己的推文下先隐藏回复再屏蔽；在别人的推文下直接屏蔽。
7. 黄推：命中语录的回复不点按钮也会自动标红；「线下课」「已私信你」这类正常回复不会被标记。
8. 设置页：切换服务商后 Key 互不覆盖；「测试连接」成功和失败都有明确提示。
