X 回复清理助手

选好服务商，填上 API Key，点「测试连接」就能用了。Key 只保存在本机浏览器。

填到 /v1 为止，插件会请求 {地址}/chat/completions。测试连接时浏览器会请你授权访问这个地址。
没有 Key？去获取 打开自己推文的详情页时自动分析回复。别人的评论区和个人主页点右下角按钮分析。 今天已自动分析 0 条。 用本地规则识别色情引流回复，标红色「黄推」，不调用 API、不花钱。 回复里出现其中任意一条，就直接标为黄推。比对时忽略空格、标点和 emoji。
